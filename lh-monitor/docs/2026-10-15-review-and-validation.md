# 검토 및 검증 기록

목표: 수원 관련 모든 유형의 공고·안내와 접수 시작을 기존 클라우드 알림 흐름으로 전달한다. 기존 이력과 주기를 보존한다.

## 별도 코드 검토에서 수정한 결함

1. 날짜만 나온 캘린더와 정확한 상세 접수시각이 별도 알림으로 발생: 정확한 시각 우선. 실패 재현 후 통과.
2. 월 이동으로 일부 일정만 창 밖으로 나가면 허위 변경 발생: 조회 창을 저장하고 창 밖 과거 일정을 보존. 실패 재현 후 통과.
3. 선착순 재고 행의 이탈/재등장 누락: 기존 ID로 변경 이벤트 생성. 실패 재현 후 통과.
4. 과거 상세 실패 메모가 보존 행에서 영구 실패 유발: 이번 현재 표시 행의 실패만 집계.

추가 검증: 조회수 무시, 실패 시 이력/정상 상태 보존, 페이지/행/식별자 검증, 순서 변경 무시, 신규 출처 소급 알림 방지, 재접수, 연락처 주소 오인 방지. 첨부파일 본문 비수집.

## 실제 조회 결과

2026-10-15 격리 실데이터 수집: 통합 4,818개 식별자, 캘린더 443개 고유 공고, 공지사항 1,437건, 입주안내 66건, 자료실 493건, 임대 공급계획 128행, 분양 공급계획 96행, 입주계획 6행. 선착순 토지 1,625행, 분양 14행, 상가 40행, 임대상가 84행. 분양전환임대/임대주택은 해당 조회에서 0행. 목록 표시 건수와 전체 페이지를 검증함.

기존 알림 이력 61개를 그대로 prefix로 보존. 가상 이벤트는 운영에 쓰지 않음. 최종 배포/클라우드 실행은 별도 최종 보고서에 기록한다.

## 남는 제한

- 첨부 본문에만 있는 지역·접수시간은 판독하지 않음. 광역 후보로 남기고 사용자가 공식 공고를 확인.
- GitHub 예약 지연, LH 장애, ChatGPT 알림 전달을 실시간/무결함으로 보장할 수 없음.
- 로그인 후 공개되는 개인별 결과나 청약 신청 제출은 자동 수행하지 않음.
- 목록은 기존 시작일 이후, 공지/입주 안내는 해당 연도, 자료실은 전체, 캘린더는 이번/다음 달을 교차 확인. 과거 소급 알림 금지.
